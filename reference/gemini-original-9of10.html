A. 이진 분류 (0 vs 1) — 시그모이드(Sigmoid)

출력 노드가 단 1개이며, 로짓 z를 0~1 사이 확률로 압축해 임계값(보통 0.5) 기준으로 두 클래스 중 하나를 판별합니다.

P(y = 1 | x) = σ(z) = 1 / (1 + e⁻ᶻ),   P(y = 0 | x) = 1 - σ(z)

· 판정 규칙: σ(z) ≥ 0.5 이면 1, 미만이면 0

B. 다중 분류 (0 ~ 9) — 소프트맥스(Softmax)

클래스 수만큼 10개의 출력 노드(z₀~z₉)를 두고, 지수함수 정규화를 거쳐 10개 확률의 총합이 정확히 1.0 (100%)이 되도록 만듭니다.

P(y = k | x) = exp(zₖ) / Σⱼ₌₀⁹ exp(zⱼ),   Σₖ₌₀⁹ P(y = k) = 1

· 판정 규칙: 확률이 가장 큰 인덱스 argmaxₖ P(y = k) 선택

C. 전체 CNN 순전파 파이프라인 6단계 한 줄 요약

  • 1입력(Input): 8×8 격자(64픽셀)의 흑백 명암을 0과 1의 수치 행렬로 표현합니다.
  • 2합성곱(Conv): 3×3 커널을 한 칸씩(Stride 1) 옮기며 국소 영역과 내적해 6×6 엣지 맵을 만듭니다.
  • 3활성화(ReLU): max(0, x)로 음수 값을 0으로 잘라내어 비선형성과 특징 대비를 높입니다.
  • 4풀링(Pooling): 2×2 구역(Stride 2)에서 최댓값/평균값을 뽑아 3×3(9개)으로 크기를 줄이고 위치 이동에 강해집니다.
  • 5완전연결(FC): 3×3 특징을 1차원 벡터(f₁~f₉)로 편 뒤 9×10 가중치 행렬과 곱하고 편향(bₖ)을 더해 10개 로짓을 구합니다.
  • 6소프트맥스(Softmax): 10개 로짓을 지수 비율로 변환하여 0~9 각 숫자일 확률(%) 분포를 출력합니다.
